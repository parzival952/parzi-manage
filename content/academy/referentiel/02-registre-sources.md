# Registre maître des sources

## 1. Mission

Ce registre contrôle toutes les sources utilisées par PARZI Academy.

Il doit empêcher :

- l'utilisation d'un texte périmé ;
- le mélange entre plusieurs territoires ;
- l'invention d'une règle par intelligence artificielle ;
- l'utilisation d'une source non officielle comme fondement principal ;
- la publication d'une question devenue juridiquement incertaine.

Une règle importante ne peut pas être enseignée sans source enregistrée.

## 2. Niveaux d'autorité

### A1 — Source normative officielle

Lois, codes, décrets, arrêtés et règlements officiels.

### A2 — Publication institutionnelle officielle

Programmes d'examen, circulaires, guides, notices et FAQ officielles.

### B — Source experte validée

Analyse juridique, publication universitaire ou support relu.

### C — Source indicative

Presse, blog, vidéo, forum, réseau social ou réponse d'intelligence
artificielle.

Une source C ne peut jamais établir seule une règle.

## 3. États des sources

- A_VERIFIER
- ACTIVE
- SURVEILLANCE
- MODIFIEE
- SUSPENDUE
- REMPLACEE
- ABROGEE
- ARCHIVEE

Une source A_VERIFIER, SUSPENDUE ou ABROGEE ne peut pas valider
définitivement une compétence.

## 4. Informations obligatoires

Chaque source doit indiquer :

- identifiant ;
- titre ;
- autorité ;
- niveau d'autorité ;
- territoire ;
- type de document ;
- adresse officielle ;
- langue ;
- version ;
- saison éventuelle ;
- date d'entrée en vigueur ;
- état ;
- date de vérification ;
- compétences concernées ;
- fréquence de surveillance.

Une information inconnue doit être écrite A_CONFIRMER.

Elle ne doit jamais être inventée.

## 5. Contrôle avant activation

Une source devient ACTIVE seulement après vérification de :

1. l'identité de l'autorité ;
2. l'adresse officielle ;
3. la version ;
4. la date d'entrée en vigueur ;
5. le territoire ;
6. la saison concernée ;
7. la présence d'exceptions ;
8. les dispositions transitoires ;
9. les contenus pédagogiques dépendants ;
10. la prochaine date de vérification.

## 6. Alertes

### INFO

Modification sans conséquence pédagogique immédiate.

### SURVEILLANCE

Un changement est possible ou annoncé.

### REVISION_REQUISE

Une nouvelle version doit être comparée avec l'ancienne.

### SUSPENSION

Les questions concernées ne doivent plus être proposées.

### CRITIQUE

Une règle enseignée pourrait être fausse ou inapplicable.

## 7. Suspension automatique

Une question doit être suspendue lorsque :

- sa source est abrogée ;
- sa source est remplacée ;
- sa version est inconnue ;
- son territoire est incertain ;
- l'article utilisé a changé ;
- plusieurs réponses deviennent défendables ;
- une décision officielle contredit la correction ;
- la date d'entrée en vigueur n'est pas connue.

## 8. Registre initial

Les sources restent A_VERIFIER jusqu'à leur validation complète.

# Règles de dépendance

Chaque leçon et chaque question juridique doivent indiquer :

- l'identifiant de la source ;
- l'article ou la section exacte ;
- la version utilisée ;
- la date de dernière vérification.

# Adoption

Aucune règle importante ne doit être publiée sans source enregistrée,
vérifiée, versionnée et reliée à son contenu pédagogique.
