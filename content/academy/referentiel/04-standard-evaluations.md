# Standard officiel des évaluations

Une évaluation doit mesurer une compétence réelle.

Elle ne doit pas seulement vérifier si l’apprenant
reconnaît une phrase déjà vue.

## Types d’évaluations

PARZI utilise :

- questions de connaissance ;
- questions de compréhension ;
- questions de distinction ;
- applications simples ;
- cas pratiques ;
- questions transversales ;
- épreuves chronométrées ;
- examens blancs.

## Qualité obligatoire

Chaque question doit posséder :

- une compétence précise ;
- une source identifiable ;
- une seule réponse défendable ;
- des choix plausibles ;
- une correction complète ;
- un niveau de difficulté ;
- un temps cible.

## Mauvaises réponses

Chaque mauvaise réponse doit correspondre à :

- une confusion fréquente ;
- une exception oubliée ;
- une mauvaise lecture ;
- une règle proche ;
- un raisonnement incomplet.

Une réponse absurde ne mesure pas la maîtrise.

## Correction obligatoire

La correction explique :

- pourquoi la bonne réponse est correcte ;
- pourquoi chaque autre réponse est fausse ;
- quelle règle devait être utilisée ;
- quel piège était présent ;
- quelle source confirme la réponse.

## Niveau de confiance

L’apprenant peut indiquer :

- certain ;
- plutôt certain ;
- hésitant ;
- réponse au hasard.

Une erreur donnée avec forte confiance
devient une faiblesse prioritaire.

## Cas pratiques

Un cas pratique doit contenir :

- des faits utiles ;
- des faits secondaires ;
- une question précise ;
- une ou plusieurs règles ;
- des informations parfois manquantes ;
- une décision à justifier.

## Examens blancs

Ils doivent mesurer :

- le score global ;
- le score par matière ;
- le temps total ;
- le temps par question ;
- les erreurs critiques ;
- les réponses incertaines ;
- les fausses certitudes.

## Suspension automatique

Une question est suspendue si :

- sa source a changé ;
- sa version est inconnue ;
- plusieurs réponses sont défendables ;
- son territoire est incertain ;
- sa correction devient obsolète ;
- sa formulation est ambiguë.

## Contrôle avant publication

Une évaluation est publiable seulement si :

- ses compétences sont identifiées ;
- ses sources sont vérifiées ;
- ses corrections sont complètes ;
- sa difficulté est justifiée ;
- son affichage mobile fonctionne ;
- aucune question n’est suspendue.

## Adoption

Ce standard est obligatoire pour les quiz,
cas pratiques et examens blancs PARZI.

**Fin du standard des évaluations — version 1.0.0**
