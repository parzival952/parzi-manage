# Moteur adaptatif PARZI Academy

Le moteur choisit la prochaine activité
selon les besoins réels de l’apprenant.

## Données utilisées

Le moteur analyse :

- les compétences travaillées ;
- les scores ;
- les erreurs ;
- les récidives ;
- le temps de réponse ;
- le niveau de confiance ;
- les révisions en retard.

## Règles de priorité

Une activité devient prioritaire si :

- la compétence est critique ;
- l’erreur se répète ;
- la réponse fausse était certaine ;
- la notion risque d’être oubliée ;
- l’examen approche ;
- la source a changé.

## Équilibre obligatoire

Le parcours doit équilibrer :

- nouvelles notions ;
- consolidation ;
- révisions ;
- cas pratiques ;
- questions mélangées ;
- examens chronométrés.

L’apprenant ne doit pas rester bloqué
uniquement sur ses faiblesses.

## Prévention de la fausse maîtrise

Une réponse correcte ne suffit pas si :

- elle a été donnée au hasard ;
- la question avait déjà été mémorisée ;
- le temps était anormalement long ;
- la notion échoue dans un autre contexte ;
- la réussite ne tient pas dans le temps.

## Décision explicable

Chaque recommandation doit indiquer :

- pourquoi l’activité est proposée ;
- quelle compétence est travaillée ;
- quelle erreur doit être corrigée ;
- combien de temps elle prendra ;
- quand la notion reviendra.

## Interdictions

Le moteur ne doit jamais :

- valider après une seule réponse ;
- cacher une faiblesse ;
- utiliser une question suspendue ;
- privilégier les XP à la maîtrise ;
- inventer une règle juridique ;
- modifier seul une correction validée.

## Adoption

Le moteur adaptatif reste au service
de la réussite réelle de l’apprenant.

Ses décisions doivent être :

- pédagogiques ;
- traçables ;
- compréhensibles ;
- révisables ;
- fondées sur des données fiables.
