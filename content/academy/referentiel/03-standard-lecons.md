# Standard officiel des leçons PARZI Academy

Chaque leçon doit produire une compétence réelle,
observable, applicable et durable.

## Ce qu’une leçon ne doit jamais être

- un simple texte à lire ;
- une vidéo sans activité ;
- une suite de définitions ;
- un quiz sans correction ;
- une récompense sans apprentissage réel.

## Objectifs obligatoires

À la fin, l’apprenant doit pouvoir :

- expliquer la notion ;
- distinguer les notions proches ;
- appliquer la règle ;
- repérer les exceptions ;
- résoudre un cas nouveau.

## Métadonnées obligatoires

Chaque leçon indique :

- son identifiant ;
- son module ;
- son territoire ;
- sa difficulté ;
- sa durée ;
- ses compétences ;
- ses prérequis ;
- ses sources ;
- sa version.

## Début obligatoire

Chaque leçon commence par :

1. une situation professionnelle ;
2. une question de départ ;
3. des objectifs mesurables ;
4. les prérequis ;
5. le vocabulaire essentiel.

## Explication obligatoire

La notion doit être présentée avec :

- la règle officielle ;
- une explication simple ;
- une explication approfondie ;
- un exemple correct ;
- un contre-exemple ;
- les exceptions importantes.

## Mise en pratique obligatoire

Chaque leçon contient :

- une pratique guidée ;
- un exercice autonome ;
- un cas professionnel ;
- une situation nouvelle ;
- une synthèse active.

## Quiz et correction

Chaque question doit expliquer :

- pourquoi la bonne réponse est correcte ;
- pourquoi chaque autre réponse est fausse ;
- quelle règle devait être utilisée ;
- quel piège était présent.

## Validation de la maîtrise

Une leçon n’est pas maîtrisée après une seule réussite.

La compétence doit revenir :

- le lendemain ;
- quelques jours plus tard ;
- dans un quiz mélangé ;
- dans un cas pratique ;
- dans une évaluation chronométrée.

## Expérience responsive

Sur mobile :

- une action principale par écran ;
- des textes courts et découpés ;
- des boutons faciles à utiliser ;
- une sauvegarde automatique ;
- une reprise exacte de la progression.

Sur ordinateur :

- source et explication côte à côte ;
- prise de notes ;
- surlignage ;
- navigation rapide ;
- affichage plein écran des examens.

## Accessibilité

Une leçon doit proposer :

- une structure lisible ;
- des titres explicites ;
- un contraste suffisant ;
- une navigation au clavier ;
- des textes compréhensibles ;
- des activités sans geste complexe obligatoire.

## Sources obligatoires

Toute règle importante doit afficher :

- l’autorité officielle ;
- le document utilisé ;
- l’article ou la section ;
- le territoire ;
- la version ;
- la date de vérification.

## Utilisation de l’intelligence artificielle

L’IA peut reformuler et expliquer un contenu validé.

Elle ne peut pas seule :

- inventer une règle ;
- choisir une réponse juridique ;
- déclarer une source actuelle ;
- publier une leçon normative.

## Contrôle avant publication

Une leçon est publiable seulement si :

- ses objectifs sont mesurables ;
- ses sources sont vérifiées ;
- ses corrections sont complètes ;
- son cas pratique fonctionne ;
- sa révision est programmée ;
- sa version mobile est testée.

## Adoption

Ce standard est obligatoire pour toutes les futures leçons.

La quantité de contenu ne doit jamais remplacer :

- la fiabilité ;
- la compréhension ;
- la pratique ;
- la mémorisation durable.

**Fin du standard officiel des leçons — version 1.0.0**
