# Cartographie maître des compétences

## 1. Finalité

Cette cartographie définit ce qu’un apprenant doit réellement savoir,
comprendre, appliquer, analyser et décider.

Elle sert de fondation à :

- la structure des parcours ;
- la rédaction des leçons ;
- la création des questions ;
- les cas pratiques ;
- les révisions espacées ;
- les examens blancs ;
- le carnet d’erreurs ;
- le moteur adaptatif ;
- l’indice de préparation ;
- la certification interne PARZI.

Aucun contenu pédagogique ne doit être publié sans être relié à au
moins une compétence de cette cartographie.

---

# 2. Structure d’une compétence

Chaque compétence possède :

- un identifiant stable ;
- un domaine ;
- un public ;
- un territoire ;
- un niveau cible ;
- une criticité ;
- des prérequis ;
- des connaissances associées ;
- des comportements observables ;
- des preuves de maîtrise ;
- des sources ;
- une règle de révision ;
- un état éditorial.

## Format d’identifiant

Les identifiants suivent cette structure :

`PARCOURS-DOMAINE-NUMÉRO`

Exemples :

- FND-MET-001 ;
- FRA-CON-004 ;
- FOO-REG-007 ;
- PRO-NEG-003 ;
- EXA-MET-005 ;
- JOU-DRO-002 ;
- CLU-REL-004 ;
- INT-OPE-003.

Un identifiant publié ne doit jamais être réutilisé pour une autre
compétence.

---

# 3. Niveaux de maîtrise

## Niveau 0 — Non abordé

L’apprenant n’a pas encore travaillé la compétence.

## Niveau 1 — Reconnaissance

L’apprenant peut :

- reconnaître un terme ;
- identifier une institution ;
- repérer une règle ;
- choisir une définition simple.

## Niveau 2 — Compréhension

L’apprenant peut :

- expliquer avec ses propres mots ;
- donner un exemple ;
- distinguer deux notions ;
- reformuler une obligation.

## Niveau 3 — Application guidée

L’apprenant peut :

- résoudre un cas simple ;
- appliquer une méthode ;
- utiliser une source fournie ;
- identifier une erreur évidente.

## Niveau 4 — Autonomie opérationnelle

L’apprenant peut :

- résoudre un cas nouveau ;
- rechercher la règle pertinente ;
- repérer une exception ;
- justifier une décision ;
- identifier les informations manquantes ;
- agir dans un temps limité.

## Niveau 5 — Maîtrise avancée

L’apprenant peut :

- traiter une situation complexe ;
- combiner plusieurs matières ;
- anticiper les risques ;
- comparer plusieurs stratégies ;
- expliquer la solution à un tiers ;
- reconnaître les limites de son analyse ;
- orienter vers le bon spécialiste.

---

# 4. Types de preuves

Chaque preuve de maîtrise possède un code.

| Code | Preuve |
|---|---|
| K | Question de connaissance |
| D | Question de distinction |
| A | Application simple |
| C | Cas pratique |
| T | Évaluation chronométrée |
| R | Réussite différée |
| X | Situation transversale |
| P | Production professionnelle |
| O | Observation d’un comportement |
| S | Simulation complète |

Une compétence critique ne peut pas être validée uniquement avec des
questions de connaissance.

---

# 5. Niveaux de criticité

## C1 — Fondamentale

Erreur gênante mais facilement corrigeable.

## C2 — Importante

Erreur susceptible de fragiliser l’examen ou une décision.

## C3 — Majeure

Erreur susceptible d’entraîner une mauvaise décision professionnelle,
contractuelle, financière ou réglementaire.

## C4 — Critique

Erreur susceptible d’exposer une personne, un mineur, un club ou une
organisation à un risque grave.

Les compétences C3 et C4 nécessitent :

- une réussite immédiate ;
- une réussite différée ;
- un cas pratique ;
- une question transversale ;
- une source actuelle ;
- une absence d’erreur critique récente.

---

# 6. Conditions générales de validation

## Compétence standard

Une compétence standard est validée avec :

- au moins 85 % sur les activités associées ;
- deux formulations différentes ;
- une réussite différée ;
- une confiance cohérente ;
- un temps compatible avec l’objectif.

## Compétence importante

Une compétence C2 nécessite également :

- une application ;
- une explication de la réponse ;
- l’identification d’au moins une erreur fréquente.

## Compétence majeure ou critique

Une compétence C3 ou C4 nécessite également :

- un cas pratique ;
- une situation mélangée ;
- une vérification différée ;
- aucune fausse certitude non corrigée ;
- une source réglementaire actuelle ;
- un score minimal de 90 % sur le contrôle final ciblé.

# 17. Matrice d’évaluation

Chaque module doit contenir au minimum :

- une activité de connaissance ;
- une activité de distinction ;
- une application ;
- une correction explicative ;
- une révision différée.

Chaque module comportant une compétence C3 ou C4 doit également contenir :

- un cas pratique ;
- une question transversale ;
- une source vérifiée ;
- une activité de confiance ;
- une activité de remédiation.

Chaque bloc complet doit se terminer par :

- une évaluation cumulative ;
- une analyse des erreurs ;
- un plan de révision ;
- une réévaluation différée.

---

# 18. Règles du moteur adaptatif

Le moteur attribue une priorité plus forte lorsque :

- la compétence est C4 ;
- la compétence est un prérequis ;
- la source a récemment changé ;
- l’apprenant a répondu faux avec confiance ;
- une erreur s’est répétée ;
- la compétence n’a pas été revue depuis longtemps ;
- la compétence est fréquemment mobilisée ;
- l’examen approche ;
- le temps de réponse se dégrade.

Le moteur ne doit pas :

- présenter uniquement des exercices faciles ;
- confondre répétition et apprentissage ;
- valider une compétence à partir d’une seule réponse ;
- cacher une faiblesse pour maintenir une progression artificielle ;
- utiliser une question suspendue ou obsolète.

---

# 19. Calcul de la couverture

La couverture d’un parcours ne correspond pas au nombre de pages vues.

Elle prend en compte :

- compétences abordées ;
- compétences évaluées ;
- compétences validées ;
- compétences révisées ;
- compétences critiques validées ;
- sources actuelles ;
- cas pratiques réalisés ;
- stabilité de la maîtrise.

Exemple de lecture :

- 100 % de contenu consulté ;
- 72 % de compétences évaluées ;
- 54 % de compétences maîtrisées ;
- 40 % de compétences critiques stabilisées.

Dans ce cas, la formation ne doit pas afficher que le parcours est
terminé ou maîtrisé.

---

# 20. Dette pédagogique

Une dette pédagogique est créée lorsqu’un apprenant avance malgré :

- une compétence prérequise fragile ;
- une erreur critique non corrigée ;
- une révision non effectuée ;
- une source devenue obsolète ;
- une réussite obtenue uniquement au hasard.

La dette pédagogique doit être visible et accompagnée d’un plan
correctif.

Elle ne doit pas bloquer toute exploration, mais elle empêche la
validation complète du parcours.

---

# 21. Critères d’acceptation d’une nouvelle compétence

Une compétence ne peut entrer dans le référentiel que si :

- elle correspond à un besoin réel ;
- elle peut être observée ;
- elle peut être évaluée ;
- elle n’est pas un doublon ;
- son niveau cible est défini ;
- sa criticité est justifiée ;
- ses prérequis sont identifiés ;
- ses preuves de maîtrise sont définies ;
- son territoire est clair ;
- ses sources pourront être documentées.

---

# 22. Gouvernance de la cartographie

Toute modification doit préciser :

- compétence ajoutée, modifiée ou retirée ;
- justification ;
- conséquences sur les leçons ;
- conséquences sur les questions ;
- conséquences sur les parcours ;
- conséquences sur les données historiques ;
- date d’application ;
- personne ou processus de validation.

Une compétence supprimée doit être archivée et non réattribuée à une
autre signification.

---

# 23. Indicateurs de qualité

La direction pédagogique surveille :

- taux de maîtrise ;
- stabilité à 7, 14 et 30 jours ;
- fausses certitudes ;
- temps de réponse ;
- récidives ;
- performance par compétence ;
- performance par question ;
- abandon ;
- contestations ;
- ambiguïtés ;
- écart entre entraînement et examen blanc ;
- écart entre confiance et performance ;
- couverture des compétences C4 ;
- actualité des sources.

Une compétence obtenant des résultats anormalement élevés ou faibles
doit être auditée.
