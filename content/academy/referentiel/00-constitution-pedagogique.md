# Constitution pédagogique de PARZI Academy

## Préambule

PARZI Academy a pour ambition de préparer des professionnels capables
de réussir un examen exigeant, mais aussi d’exercer leur activité avec
compétence, intégrité, discernement et responsabilité.

La plateforme ne doit jamais devenir :

- une accumulation de textes à lire ;
- une collection de quiz superficiels ;
- un système distribuant des récompenses sans apprentissage réel ;
- une source de règles juridiques non vérifiées ;
- une promesse trompeuse de réussite garantie ;
- une copie simplifiée d’un programme officiel ;
- un outil donnant une impression de compétence sans maîtrise durable.

PARZI Academy doit construire une compétence observable, mesurable,
transférable et conservée dans le temps.

---

# Article 1 — Mission fondamentale

La mission de PARZI Academy est de donner à chaque apprenant sérieux
les meilleures conditions possibles pour :

1. comprendre les règles applicables ;
2. mémoriser durablement les connaissances essentielles ;
3. appliquer les règles dans des situations nouvelles ;
4. analyser un cas avec méthode ;
5. identifier les risques et les exceptions ;
6. répondre efficacement sous contrainte de temps ;
7. reconnaître les limites de sa compétence ;
8. adopter une conduite professionnelle responsable ;
9. réussir les évaluations officielles visées ;
10. exercer ensuite de façon crédible et éthique.

La réussite à un examen ne peut jamais être garantie.

PARZI Academy doit en revanche pouvoir démontrer :

- ce qui a été enseigné ;
- ce qui a été évalué ;
- ce qui est maîtrisé ;
- ce qui reste fragile ;
- les sources utilisées ;
- la version réglementaire étudiée ;
- la méthode employée pour calculer la préparation.

---

# Article 2 — Publics concernés

PARZI Academy pourra accueillir plusieurs publics.

## 2.1 Candidats agents sportifs

Le parcours doit préparer aux connaissances, raisonnements,
automatismes et méthodes nécessaires à l’examen concerné.

## 2.2 Agents déjà en activité

Le parcours doit permettre :

- l’actualisation réglementaire ;
- le perfectionnement professionnel ;
- la révision des fondamentaux ;
- l’analyse de situations complexes ;
- la prévention des risques.

## 2.3 Joueurs et joueuses

Les contenus dédiés doivent leur permettre de comprendre :

- leurs droits ;
- leurs obligations ;
- le rôle exact d’un agent ;
- les documents qu’ils signent ;
- les risques de conflit d’intérêts ;
- les étapes d’une carrière ;
- les comportements professionnels attendus.

## 2.4 Clubs et organisations

Les contenus dédiés doivent les aider à comprendre :

- le cadre de collaboration avec les agents ;
- les responsabilités respectives ;
- les opérations contractuelles ;
- les obligations documentaires ;
- les risques juridiques, humains et réputationnels.

## 2.5 Familles et représentants légaux

Un parcours spécifique devra traiter :

- l’accompagnement des mineurs ;
- la vigilance contractuelle ;
- les promesses irréalistes ;
- la protection humaine et financière ;
- les interlocuteurs légitimes ;
- les signaux d’alerte.

---

# Article 3 — Séparation obligatoire des parcours

Les réglementations ne doivent jamais être mélangées.

## 3.1 Parcours France — Licence d’agent sportif FFF

Ce parcours est gouverné par :

- le droit français ;
- le Code du sport ;
- les textes réglementaires applicables ;
- les règlements officiels de la FFF ;
- les documents officiels du CNOSF ;
- les règlements nationaux et internationaux applicables à l’épreuve.

## 3.2 Parcours FIFA

Ce parcours est gouverné par :

- la réglementation FIFA applicable ;
- les circulaires officielles ;
- les documents d’étude officiels de l’édition concernée ;
- les règles d’examen publiées par la FIFA.

## 3.3 Parcours professionnel

Ce parcours traite de l’exercice réel du métier :

- organisation de l’activité ;
- développement du réseau ;
- analyse de joueurs ;
- relation avec les clubs ;
- négociation ;
- communication ;
- gestion de carrière ;
- conformité ;
- protection des personnes ;
- gestion de crise ;
- opérations internationales.

## 3.4 Principe de cloisonnement territorial

Toute règle doit porter au minimum les métadonnées suivantes :

- territoire ;
- autorité émettrice ;
- compétition ou activité concernée ;
- version ;
- date d’entrée en vigueur ;
- date de dernière vérification ;
- statut actuel ;
- texte remplacé, le cas échéant.

Une règle française ne doit jamais être présentée comme une règle FIFA.

Une règle FIFA ne doit jamais être présentée comme directement
applicable en France sans analyse du cadre français.

---

# Article 4 — Hiérarchie des sources

PARZI Academy utilise une hiérarchie stricte.

## Niveau 1 — Sources normatives officielles

- lois ;
- codes ;
- décrets ;
- arrêtés ;
- règlements officiels ;
- décisions juridictionnelles pertinentes ;
- textes publiés par les autorités compétentes.

## Niveau 2 — Publications officielles d’application

- circulaires ;
- guides officiels ;
- programmes d’examen ;
- notices ;
- FAQ officielles ;
- communiqués réglementaires.

## Niveau 3 — Sources explicatives contrôlées

- doctrine juridique reconnue ;
- publications universitaires ;
- commentaires rédigés ou validés par un spécialiste ;
- supports pédagogiques internes validés.

## Niveau 4 — Sources contextuelles

- presse spécialisée ;
- retours d’expérience ;
- témoignages ;
- exemples professionnels.

Une source de niveau 4 ne peut jamais suffire à établir une règle.

Une réponse générée par intelligence artificielle ne constitue jamais
une source juridique.

---

# Article 5 — Registre obligatoire des sources

Toute notion juridique importante doit être reliée à une fiche source.

La fiche source contient :

- identifiant unique ;
- titre officiel ;
- organisme émetteur ;
- territoire ;
- type de document ;
- URL officielle ;
- article ou section ;
- date de publication ;
- date d’entrée en vigueur ;
- version applicable ;
- date de vérification ;
- personne ou processus ayant vérifié la source ;
- état : actif, modifié, remplacé, abrogé ou en attente ;
- notions pédagogiques dépendantes ;
- questions dépendantes ;
- leçons dépendantes.

Lorsqu’une source change, PARZI doit pouvoir identifier immédiatement
tous les contenus susceptibles d’être devenus obsolètes.

---

# Article 6 — Modèle de compétence

La compétence ne se réduit pas à la mémorisation.

Chaque notion est évaluée sur six dimensions.

## 6.1 Connaître

L’apprenant peut restituer la règle, la définition ou le principe.

## 6.2 Comprendre

L’apprenant peut expliquer la règle avec ses propres mots.

## 6.3 Distinguer

L’apprenant peut différencier deux règles proches et éviter une confusion.

## 6.4 Appliquer

L’apprenant peut utiliser la règle dans un cas concret.

## 6.5 Analyser

L’apprenant peut identifier :

- les faits pertinents ;
- la question posée ;
- la règle applicable ;
- les exceptions ;
- les risques ;
- les informations manquantes.

## 6.6 Décider professionnellement

L’apprenant peut choisir une action raisonnable et expliquer :

- pourquoi elle est adaptée ;
- quelles preuves conserver ;
- quel spécialiste consulter ;
- quel risque éviter ;
- quelle limite ne pas franchir.

---

# Article 7 — Cycle pédagogique PARZI

Chaque compétence suit un cycle complet.

## Étape 1 — Activation

Une situation concrète révèle ce que l’apprenant croit déjà savoir.

## Étape 2 — Problématisation

Une question professionnelle donne un objectif à l’apprentissage.

## Étape 3 — Règle officielle

Le texte applicable est présenté avec son origine et sa version.

## Étape 4 — Explication guidée

La règle est expliquée :

- en langage simple ;
- avec le vocabulaire professionnel ;
- sans déformer sa portée ;
- en distinguant principe et exception.

## Étape 5 — Exemple positif

Un exemple montre une application correcte.

## Étape 6 — Contre-exemple

Un exemple incorrect révèle une erreur fréquente.

## Étape 7 — Pratique guidée

L’apprenant résout un premier problème avec assistance.

## Étape 8 — Rappel actif

L’apprenant répond sans consulter immédiatement la leçon.

## Étape 9 — Correction explicative

La correction explique :

- pourquoi la bonne réponse est correcte ;
- pourquoi chaque autre réponse est incorrecte ;
- quelle règle devait être mobilisée ;
- quel piège était présent.

## Étape 10 — Transfert

Une nouvelle situation vérifie que l’apprenant sait réutiliser la règle.

## Étape 11 — Révision différée

La notion revient après un délai adapté.

## Étape 12 — Validation durable

La compétence est confirmée dans un contexte différent et mélangé.

---

# Article 8 — Standard obligatoire des leçons

Une leçon publiable doit comporter :

- identifiant stable ;
- titre précis ;
- place dans le référentiel ;
- public concerné ;
- territoire ;
- niveau ;
- durée indicative ;
- prérequis ;
- objectifs mesurables ;
- compétences travaillées ;
- vocabulaire essentiel ;
- situation d’ouverture ;
- règle officielle ;
- explication simple ;
- développement approfondi ;
- exemples ;
- contre-exemples ;
- exceptions ;
- erreurs fréquentes ;
- cas professionnel ;
- synthèse active ;
- questions d’entraînement ;
- correction complète ;
- sources ;
- version réglementaire ;
- date de dernière vérification ;
- critères de validation ;
- activités de révision ;
- historique des modifications.

Une leçon incomplète ne doit pas pouvoir être publiée.

---

# Article 9 — Standard obligatoire des questions

Chaque question doit posséder une fiche interne contenant :

- identifiant stable ;
- compétence évaluée ;
- objectif ;
- territoire ;
- source officielle ;
- article ou section ;
- version ;
- difficulté ;
- type de raisonnement ;
- énoncé ;
- choix proposés ;
- bonne réponse ;
- justification de la bonne réponse ;
- justification de chaque mauvaise réponse ;
- piège pédagogique visé ;
- erreur fréquente observée ;
- temps cible ;
- date de validation ;
- auteur ;
- relecteur ;
- statistiques de performance ;
- indice d’ambiguïté ;
- état de publication.

Une question ne doit pas être conservée lorsque :

- plusieurs réponses peuvent raisonnablement être défendues ;
- la source n’est plus actuelle ;
- le vocabulaire est trompeur sans intention pédagogique ;
- la difficulté vient uniquement d’une formulation confuse ;
- la correction n’explique pas les réponses incorrectes ;
- la question mesure autre chose que la compétence annoncée.

---

# Article 10 — Typologie des évaluations

PARZI Academy utilise plusieurs formats.

## 10.1 Questions de connaissance

Elles vérifient une information ou une règle précise.

## 10.2 Questions de compréhension

Elles vérifient que l’apprenant comprend la portée d’une règle.

## 10.3 Questions de distinction

Elles opposent des notions proches.

## 10.4 Questions d’application

Elles placent la règle dans une situation concrète.

## 10.5 Cas pratiques courts

Ils nécessitent plusieurs étapes de raisonnement.

## 10.6 Cas pratiques longs

Ils comportent :

- des faits utiles ;
- des faits secondaires ;
- des informations manquantes ;
- plusieurs risques ;
- plusieurs décisions possibles.

## 10.7 Questions transversales

Elles mobilisent plusieurs matières simultanément.

## 10.8 Simulations d’examen

Elles reproduisent autant que possible :

- la structure officielle connue ;
- le niveau de pression ;
- la gestion du temps ;
- l’alternance des matières ;
- l’absence d’aide ;
- les conditions matérielles pertinentes.

---

# Article 11 — Maîtrise et progression

Le simple achèvement d’une leçon ne prouve pas la maîtrise.

## 11.1 États d’une compétence

Chaque compétence peut être :

- non abordée ;
- découverte ;
- fragile ;
- en consolidation ;
- opérationnelle ;
- maîtrisée ;
- à réviser ;
- obsolète en raison d’un changement réglementaire.

## 11.2 Seuils internes

Les seuils PARZI sont des repères pédagogiques internes.

- moins de 60 % : non acquise ;
- 60 à 74 % : fragile ;
- 75 à 84 % : en développement ;
- 85 à 92 % : opérationnelle ;
- 93 à 100 % : niveau avancé à confirmer.

## 11.3 Validation durable

Une compétence n’est considérée comme maîtrisée que si elle est réussie :

- immédiatement après l’apprentissage ;
- après un délai ;
- dans une formulation différente ;
- dans un contexte mélangé ;
- dans un cas pratique ;
- avec un temps de réponse acceptable.

## 11.4 Progression honnête

PARZI ne doit pas débloquer artificiellement une compétence uniquement
pour maintenir l’engagement de l’utilisateur.

La motivation ne doit jamais être obtenue au prix d’une fausse
représentation du niveau réel.

---

# Article 12 — Répétition espacée

Le moteur organise des rappels selon :

- la difficulté de la notion ;
- la réussite précédente ;
- le temps de réponse ;
- le niveau de confiance ;
- le nombre de récidives ;
- la proximité de l’examen ;
- l’importance de la compétence ;
- la date de modification de la source.

Le calendrier initial peut suivre cette logique :

- rappel immédiat ;
- rappel le lendemain ;
- rappel après quelques jours ;
- rappel après une semaine ;
- rappel après deux semaines ;
- rappel après un mois.

Ces délais ne sont pas rigides.

Ils doivent être adaptés aux performances réelles de l’apprenant.

---

# Article 13 — Entrelacement des matières

Après l’acquisition initiale, les matières doivent être mélangées.

L’apprenant ne doit pas toujours savoir à l’avance si une question
relève :

- du droit des contrats ;
- du droit social ;
- de la fiscalité ;
- du mandat ;
- de la réglementation sportive ;
- de l’éthique ;
- de la protection des mineurs.

L’objectif est de lui apprendre à identifier lui-même la matière et
la règle pertinente.

---

# Article 14 — Carnet d’erreurs intelligent

Chaque erreur doit produire une information utile.

Le carnet d’erreurs enregistre :

- compétence ;
- question ;
- réponse donnée ;
- bonne réponse ;
- source ;
- temps ;
- confiance déclarée ;
- date ;
- nombre de tentatives ;
- récidive éventuelle ;
- cause probable ;
- activité corrective ;
- prochaine révision ;
- résultat ultérieur.

## Causes possibles

- règle inconnue ;
- règle mal comprise ;
- confusion ;
- exception oubliée ;
- lecture insuffisante ;
- raisonnement incomplet ;
- réponse précipitée ;
- mauvaise gestion du temps ;
- mémorisation fragile ;
- confiance excessive ;
- difficulté de transfert ;
- question potentiellement ambiguë.

La correction proposée doit dépendre de la cause.

---

# Article 15 — Mesure de la confiance

Lorsque cela est pertinent, l’apprenant indique son niveau de confiance.

Exemple :

- certain ;
- plutôt certain ;
- hésitant ;
- réponse au hasard.

Une réponse fausse donnée avec une forte confiance doit être traitée
comme une faiblesse prioritaire.

Une réponse correcte donnée au hasard ne doit pas être considérée comme
une preuve suffisante de maîtrise.

---

# Article 16 — Moteur adaptatif

Le moteur choisit la prochaine activité selon une décision explicable.

Il prend notamment en compte :

- importance réglementaire ;
- importance à l’examen ;
- niveau actuel ;
- stabilité de la maîtrise ;
- probabilité d’oubli ;
- erreurs récentes ;
- erreurs anciennes non corrigées ;
- récidives ;
- temps de réponse ;
- niveau de confiance ;
- couverture du programme ;
- proximité de l’examen ;
- disponibilité quotidienne ;
- fatigue déclarée ;
- accessibilité.

Le moteur ne doit pas enfermer l’apprenant uniquement dans ses
faiblesses.

Il doit maintenir un équilibre entre :

- consolidation ;
- progression ;
- révision ;
- application ;
- confiance ;
- préparation aux conditions réelles.

---

# Article 17 — Indice de préparation

PARZI ne doit pas afficher une probabilité fictive de réussite.

Il peut afficher un indice de préparation fondé sur :

- couverture du programme ;
- maîtrise par matière ;
- stabilité dans le temps ;
- performance chronométrée ;
- cas pratiques ;
- examens blancs ;
- erreurs critiques ;
- récidives ;
- confiance excessive ;
- actualité des sources étudiées ;
- régularité de travail.

Chaque composante doit être consultable.

L’apprenant doit comprendre pourquoi son indice augmente ou diminue.

---

# Article 18 — Examens blancs

Un examen blanc doit avoir un objectif défini.

## Niveaux

1. mini-évaluation ;
2. évaluation thématique ;
3. évaluation cumulative ;
4. simulation chronométrée ;
5. examen blanc complet ;
6. examen adaptatif ;
7. simulation finale.

## Après chaque examen blanc

L’apprenant reçoit :

- score global ;
- score par compétence ;
- score par matière ;
- temps global ;
- temps par question ;
- erreurs critiques ;
- réponses incertaines ;
- fausses certitudes ;
- sujets non couverts ;
- plan correctif ;
- date recommandée du prochain examen.

Le corrigé ne doit pas seulement afficher des lettres ou des couleurs.

---

# Article 19 — Parcours de remédiation

Lorsqu’une faiblesse est détectée, PARZI choisit une remédiation adaptée.

Exemples :

- explication reformulée ;
- schéma ;
- comparaison de notions ;
- exemple supplémentaire ;
- contre-exemple ;
- retour au texte officiel ;
- exercice guidé ;
- série de discrimination ;
- cas pratique ;
- rappel différé ;
- entretien avec un formateur ;
- signalement d’une question ambiguë.

Répéter exactement la même question ne constitue pas toujours une
remédiation suffisante.

---

# Article 20 — Expérience responsive

## Sur mobile

L’expérience doit permettre :

- une action principale claire ;
- une lecture confortable ;
- des boutons accessibles ;
- une sauvegarde automatique ;
- une reprise exacte ;
- des sessions courtes ;
- un mode hors perturbation ;
- des corrections lisibles ;
- un accès rapide aux définitions ;
- une progression visible sans surcharge.

## Sur ordinateur

L’expérience peut proposer :

- source et explication côte à côte ;
- prise de notes ;
- surlignage ;
- navigation par articles ;
- recherche ;
- comparaison de versions ;
- tableau de compétences ;
- examen plein écran ;
- analyse approfondie des résultats.

## Continuité

Le passage d’un appareil à un autre ne doit pas faire perdre :

- la progression ;
- les réponses ;
- les notes ;
- la position de lecture ;
- les révisions programmées.

---

# Article 21 — Accessibilité et équité

La conception doit tenir compte :

- des troubles de la lecture ;
- des déficiences visuelles ;
- des déficiences motrices ;
- des difficultés de concentration ;
- des besoins d’aménagement ;
- des différences de niveau initial ;
- de la langue de l’apprenant ;
- de la qualité de la connexion ;
- du matériel disponible.

Une difficulté d’interface ne doit pas être confondue avec une
difficulté de connaissance.

---

# Article 22 — Usage de l’intelligence artificielle

L’intelligence artificielle peut :

- reformuler une explication validée ;
- proposer un exemple à faire vérifier ;
- adapter le niveau de langage ;
- aider à classer une erreur ;
- suggérer une activité de remédiation ;
- générer un brouillon pédagogique ;
- assister la recherche documentaire ;
- expliquer un raisonnement à partir de sources validées.

Elle ne peut pas, seule :

- créer une règle juridique considérée comme vraie ;
- modifier une bonne réponse juridique ;
- publier une leçon normative ;
- déclarer une source à jour ;
- inventer une jurisprudence ;
- promettre une réussite ;
- remplacer un professionnel compétent ;
- produire une recommandation personnalisée dépassant le cadre prévu.

Toute production juridique générée doit être reliée à une source et
soumise au processus de validation prévu.

---

# Article 23 — Gouvernance éditoriale

## Rôles minimaux

### Direction pédagogique

Elle garantit :

- la cohérence du programme ;
- la qualité des objectifs ;
- la progression ;
- les méthodes d’évaluation ;
- le respect de cette constitution.

### Référent juridique ou réglementaire

Il vérifie :

- les sources ;
- l’interprétation ;
- la version ;
- le territoire ;
- les corrections.

### Auteur pédagogique

Il transforme les connaissances en activités apprenables.

### Relecteur indépendant

Il recherche :

- ambiguïtés ;
- erreurs ;
- raccourcis ;
- biais ;
- contradictions ;
- difficultés artificielles.

### Responsable des données pédagogiques

Il surveille :

- performance des questions ;
- anomalies ;
- taux d’abandon ;
- équité ;
- qualité de l’indice de préparation.

Une personne peut occuper plusieurs rôles au début du projet, mais les
responsabilités doivent rester distinguées.

---

# Article 24 — Validation avant publication

Un contenu ne peut être publié que si les contrôles suivants sont validés.

## Contrôle réglementaire

- source officielle disponible ;
- version identifiée ;
- territoire identifié ;
- interprétation vérifiée ;
- aucune contradiction connue.

## Contrôle pédagogique

- objectif mesurable ;
- explication compréhensible ;
- exemples pertinents ;
- pratique active ;
- correction détaillée ;
- révision prévue.

## Contrôle d’évaluation

- une seule réponse défendable lorsque le format l’exige ;
- difficulté justifiée ;
- absence d’indice involontaire ;
- distracteurs plausibles ;
- compétence réellement mesurée.

## Contrôle technique

- fonctionnement mobile ;
- fonctionnement ordinateur ;
- sauvegarde ;
- accessibilité ;
- absence d’erreur bloquante ;
- données correctement enregistrées.

---

# Article 25 — États éditoriaux

Chaque contenu possède un état.

- brouillon ;
- en recherche ;
- en rédaction ;
- en validation juridique ;
- en validation pédagogique ;
- prêt à tester ;
- en expérimentation ;
- publié ;
- à réviser ;
- suspendu ;
- archivé.

Un contenu suspendu ne doit plus participer aux évaluations notées.

---

# Article 26 — Gestion des changements réglementaires

Lorsqu’un changement est détecté :

1. la source est marquée comme potentiellement modifiée ;
2. les contenus dépendants sont identifiés ;
3. les questions concernées sont suspendues si nécessaire ;
4. la nouvelle version est analysée ;
5. les différences sont documentées ;
6. les contenus sont corrigés ;
7. les corrections sont validées ;
8. la date de mise à jour est enregistrée ;
9. les apprenants concernés sont informés ;
10. les maîtrises devenues obsolètes peuvent être réévaluées.

Une mise à jour ne doit pas effacer l’historique précédent.

---

# Article 27 — Internationalisation

L’expansion mondiale suit une logique juridictionnelle.

Chaque pays ou territoire doit disposer :

- d’un référentiel séparé ;
- de sources locales ;
- d’un responsable de validation ;
- d’un système de version ;
- d’une terminologie adaptée ;
- d’avertissements sur le champ d’application.

La traduction d’une règle étrangère ne suffit pas à créer une formation
juridiquement fiable dans un nouveau pays.

---

# Article 28 — Protection des personnes

Les contenus doivent promouvoir :

- l’intégrité ;
- la confidentialité ;
- la protection des mineurs ;
- la prévention des discriminations ;
- la prévention des violences ;
- la prévention du harcèlement ;
- la prévention de la corruption ;
- la gestion des conflits d’intérêts ;
- le respect de la dignité ;
- le signalement responsable.

Les cas pédagogiques doivent éviter d’exposer des personnes réelles sans
nécessité et sans base légitime.

---

# Article 29 — Données pédagogiques

Les données collectées doivent être limitées à ce qui est utile.

La plateforme doit distinguer :

- données de compte ;
- données de progression ;
- données d’évaluation ;
- données de comportement pédagogique ;
- notes personnelles ;
- données sensibles éventuelles.

Les données ne doivent pas être utilisées pour humilier, discriminer ou
présenter une faiblesse temporaire comme une incapacité définitive.

---

# Article 30 — Mesures de qualité

La qualité ne se résume pas au taux de complétion.

PARZI surveille notamment :

- progression réelle ;
- conservation des acquis ;
- transfert vers des cas nouveaux ;
- évolution des erreurs ;
- récidives ;
- questions contestées ;
- ambiguïtés ;
- temps d’apprentissage ;
- régularité ;
- abandon ;
- satisfaction ;
- confiance ;
- performance aux examens blancs ;
- actualité des contenus ;
- accessibilité ;
- incidents réglementaires.

Un taux de réussite artificiellement élevé peut révéler une formation
trop facile et non une formation de qualité.

---

# Article 31 — Culture de l’amélioration

Chaque retour doit pouvoir produire une amélioration.

Les retours peuvent venir :

- des apprenants ;
- des formateurs ;
- des juristes ;
- des agents ;
- des joueurs ;
- des clubs ;
- des familles ;
- des statistiques ;
- des changements réglementaires ;
- des erreurs détectées.

Toute correction importante doit être documentée.

---

# Article 32 — Limites et transparence

PARZI Academy doit indiquer clairement :

- qu’il s’agit d’une formation indépendante ;
- les partenariats réellement existants ;
- l’absence de partenariat officiel lorsqu’il n’existe pas ;
- les sources utilisées ;
- la version du programme ;
- la date de dernière mise à jour ;
- les limites de l’indice de préparation ;
- l’absence de garantie de réussite ;
- la nécessité éventuelle de consulter un professionnel.

La confiance doit être gagnée par la qualité et non par une présentation
trompeuse.

---

# Article 33 — Engagement envers l’apprenant

PARZI Academy s’engage à :

- ne pas lui mentir sur son niveau ;
- ne pas cacher ses faiblesses ;
- lui expliquer comment progresser ;
- protéger sa progression ;
- respecter son rythme sans diminuer l’exigence ;
- distinguer erreur et incapacité ;
- valoriser l’effort utile ;
- lui donner accès aux sources ;
- corriger rapidement les contenus erronés ;
- construire son autonomie.

---

# Article 34 — Engagement attendu de l’apprenant

L’apprenant doit :

- travailler régulièrement ;
- répondre sans tricher ;
- consulter les corrections ;
- accepter de revoir une notion fragile ;
- signaler une ambiguïté ;
- distinguer compréhension et mémorisation ;
- réaliser les examens blancs dans des conditions sérieuses ;
- respecter les règles d’intégrité ;
- ne pas confondre progression virtuelle et compétence réelle.

---

# Article 35 — Clause de non-régression

Aucune évolution commerciale, graphique ou technique ne doit réduire :

- la qualité des sources ;
- la profondeur des corrections ;
- la traçabilité ;
- la protection des apprenants ;
- la fiabilité des évaluations ;
- l’accessibilité ;
- l’honnêteté de l’indice de préparation.

L’engagement et la gamification restent au service de l’apprentissage.

Ils ne doivent jamais le remplacer.

---

# Article 36 — Ordre de construction de PARZI Academy

Le développement respecte cet ordre :

1. constitution pédagogique ;
2. cartographie des compétences ;
3. registre des sources ;
4. standard des leçons ;
5. standard des évaluations ;
6. modèle de données pédagogiques ;
7. contenus fondamentaux ;
8. moteur de révision ;
9. carnet d’erreurs ;
10. examens blancs ;
11. indice de préparation ;
12. validation externe ;
13. amélioration continue.

Le volume de contenu ne doit jamais être privilégié au détriment de sa
fiabilité.

# Adoption

La présente constitution est normative.

Tout nouveau module, toute leçon, toute question, toute fonctionnalité
d’évaluation et tout système adaptatif de PARZI Academy doivent être
compatibles avec ses principes.

Toute exception doit être :

- explicite ;
- motivée ;
- documentée ;
- limitée dans le temps ;
- validée par la direction pédagogique.
