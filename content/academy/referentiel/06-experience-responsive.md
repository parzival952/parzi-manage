# Expérience responsive PARZI Academy

L’interface doit faciliter l’apprentissage,
jamais ajouter une difficulté inutile.

## Principes généraux

Chaque écran doit être :

- clair ;
- rapide ;
- lisible ;
- accessible ;
- cohérent ;
- adapté à l’appareil utilisé.

## Expérience mobile

Sur mobile :

- une action principale par écran ;
- des textes découpés ;
- de grands boutons ;
- une progression visible ;
- une sauvegarde automatique ;
- une reprise exacte.

## Sessions courtes

Le mobile doit proposer :

- révision en 5 minutes ;
- quiz rapide ;
- carnet d’erreurs ;
- rappel quotidien ;
- reprise d’une leçon ;
- prochaine activité prioritaire.

## Expérience ordinateur

Sur ordinateur :

- source et explication côte à côte ;
- prise de notes ;
- surlignage ;
- recherche ;
- comparaison de versions ;
- examen blanc plein écran.

## Continuité entre appareils

Le changement d’appareil conserve :

- la progression ;
- les réponses ;
- les notes ;
- la position de lecture ;
- les révisions prévues ;
- le temps déjà utilisé.

## Accessibilité

L’interface doit permettre :

- navigation au clavier ;
- contraste suffisant ;
- zoom sans blocage ;
- titres structurés ;
- messages compréhensibles ;
- utilisation sans geste complexe.

## Mode examen

Le mode examen doit proposer :

- chronomètre visible ;
- navigation entre questions ;
- marquage des questions difficiles ;
- sauvegarde sécurisée ;
- avertissement avant validation ;
- absence de distraction.

## Adoption

Cette expérience est obligatoire pour :

- les leçons ;
- les quiz ;
- les cas pratiques ;
- les révisions ;
- les examens blancs ;
- les tableaux de progression.
