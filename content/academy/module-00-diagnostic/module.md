# Diagnostic initial et méthode de réussite

## Pourquoi ce module existe

PARZI Academy ne commence pas par un long cours théorique.

Elle commence par une évaluation permettant d’identifier :

- les connaissances déjà maîtrisées ;
- les matières fragiles ;
- les erreurs de raisonnement ;
- les difficultés de lecture ;
- la capacité à résoudre un cas pratique ;
- la gestion du temps ;
- le niveau de confiance du candidat.

Le diagnostic ne sert pas à juger l’apprenant.

Il sert à construire son parcours de progression.

## Objectifs

À la fin de ce module, l’apprenant doit être capable de :

1. comprendre l’organisation générale de l’examen ;
2. identifier ses principales forces ;
3. identifier ses principales faiblesses ;
4. distinguer connaissance, compréhension et application ;
5. reconnaître ses erreurs de méthode ;
6. recevoir un premier plan de révision personnalisé.

## Règle fondamentale

Une réponse correcte donnée au hasard ne constitue pas une compétence maîtrisée.

Une réponse incorrecte accompagnée d’un bon début de raisonnement peut révéler une compétence en cours d’acquisition.

PARZI Academy analyse donc :

- la réponse ;
- le temps utilisé ;
- le degré de confiance ;
- la justification ;
- le type d’erreur.

## Les six dimensions évaluées

### 1. Compréhension juridique

Capacité à lire une règle, identifier ses conditions et distinguer le principe de l’exception.

### 2. Droit des contrats

Capacité à comprendre les engagements, les parties, les obligations, la durée et les conséquences d’un contrat.

### 3. Environnement sportif

Compréhension des acteurs, institutions et responsabilités présents dans l’écosystème sportif.

### 4. Réglementation du football

Capacité à retrouver et appliquer les règlements pertinents à une situation donnée.

### 5. Cas pratique

Capacité à identifier le problème, sélectionner la règle applicable et construire une réponse justifiée.

### 6. Gestion de l’épreuve

Capacité à gérer le temps, l’incertitude, les questions à réponses multiples et les formulations trompeuses.

## Déroulement du diagnostic

Le diagnostic comporte cinq parties :

1. questionnaire de positionnement ;
2. questions de connaissances ;
3. questions de compréhension ;
4. mini-cas pratiques ;
5. analyse personnelle des réponses.

## Engagement de l’apprenant

L’apprenant s’engage à :

- répondre sans aide extérieure ;
- ne pas rechercher les réponses ;
- indiquer honnêtement son niveau de confiance ;
- terminer le diagnostic dans le temps prévu ;
- considérer ses erreurs comme des informations utiles.

## Résultat attendu

À la fin, l’apprenant reçoit :

- son profil pédagogique ;
- son niveau initial ;
- sa carte de compétences ;
- son carnet d’erreurs ;
- ses trois priorités ;
- son premier programme de révision ;
- son XP de départ ;
- son premier trophée.
