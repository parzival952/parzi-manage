# Tome I — Guide de lecture

## Objet

Le Tome I est organisé en trois documents complémentaires afin de conserver toute la profondeur du travail sans imposer un dossier de près de seize mille mots à chaque lecteur.

| Document | Rôle | Statut |
|---|---|---|
| `TOME_I_CONSTITUTION_CENTRALE.md` | Texte court destiné au fondateur, aux dirigeants et aux équipes | Version 1.0 validée |
| `TOME_I_VISION_FONDATRICE.md` | Dossier maître détaillé : sources, raisonnements, risques, contre-audit et annexes | Archive de raisonnement v0.5 |
| `TOME_I_REGISTRE_DECISIONS.md` | Registre opérationnel des décisions TI-D001 à TI-D030 | Version 1.0; vingt-huit décisions validées et deux expérimentales |

## Ordre de lecture

1. lire la Constitution centrale ;
2. examiner le Registre des décisions ;
3. consulter le dossier maître pour comprendre un raisonnement, une limite ou une délégation ;
4. utiliser le registre pour toute modification future ;
5. conserver la Constitution centrale et le registre synchronisés ;
6. consulter les Tomes spécialisés avant toute proposition d’exécution.

## Autorité documentaire

- Le dossier maître conserve le raisonnement complet et l’historique de reconstruction.
- Le registre est la source de vérité du statut des décisions TI-D001 à TI-D030.
- La Constitution centrale version 1.0 est le texte de référence actif du Tome I.
- Le dossier maître conserve les raisonnements et propositions ayant conduit à la version 1.0 ; il ne doit pas être réécrit pour simuler une validation antérieure.
- En cas de contradiction, la Constitution centrale et le registre sont examinés ensemble ; le dossier maître fournit l’historique et aucune correction silencieuse n’est autorisée.
- Aucun de ces documents ne prouve qu’une fonctionnalité existe ou qu’une décision est exécutée dans le produit.

## Règle de synchronisation

Toute modification d’une décision fondatrice doit :

1. citer son identifiant TI-D ;
2. mettre à jour son statut dans le registre ;
3. indiquer la décision du fondateur et son motif ;
4. corriger la Constitution centrale si son sens change ;
5. conserver l’ancienne formulation et la raison du remplacement ;
6. vérifier les Tomes spécialisés affectés ;
7. obtenir une autorisation séparée avant tout changement applicatif.
